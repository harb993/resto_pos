===========================================================
  أبو الدهب — مشاوي شاورما كشري
  برنامج الكاشير — التشغيل لأول مرة
===========================================================

1) التثبيت
   • قبل فك الضغط (اختياري لكن أفضل): كليك يمين على ملف الـ zip
     ← Properties ← علّم  Unblock  (إلغاء الحظر) ← OK.
   • فك ضغط الملف، وانقل مجلد  aboeldahab  إلى سطح المكتب
     (أو أي مكان دائم على الجهاز — ليس داخل مجلد التنزيلات
     وليس داخل Program Files).
   • افتح المجلد وشغّل  AboElDahab.exe  (عليه شعار المطعم).
   • عند أول تشغيل يضع البرنامج اختصاراً باسم «أبو الدهب»
     بشعار المطعم على سطح المكتب — من بعدها افتح البرنامج منه.
   • إذا ظهرت رسالة ويندوز الزرقاء «Windows protected your PC»
     اضغط  More info  ثم  Run anyway  — تظهر لأن البرنامج غير
     موقَّع بشهادة تجارية.
   • في ويندوز 11 فقط: إذا قال ويندوز إن «Smart App Control»
     حظر البرنامج ولم يظهر زر Run anyway، فلا يمكن السماح له
     وحده. أوقف الخاصية من:  Windows Security ← App & browser
     control ← Smart App Control ← Off  (انتبه: إعادة تشغيلها
     بعد ذلك قد تحتاج إعادة تثبيت ويندوز).

2) التفعيل (مرة واحدة لكل جهاز)
   • أول شاشة هي «تفعيل البرنامج» وعليها «رقم هذا الجهاز».
   • على جهازك أنت (الذي عليه الملف license-private.pem):
         node tools/license-keygen.mjs sign  رقم-الجهاز
   • الصق المفتاح الناتج في الشاشة واضغط «تفعيل».

3) الدخول
   • المدير:  admin  /  admin123   — غيّر كلمة المرور فوراً
     من الإعدادات ← الأمان.

4) الطابعات (مهم قبل أول طلب)
   • ثبّت تعريف طابعات XPrinter على الجهاز أولاً.
   • الإعدادات ← 🖨️ الطابعات — ستجد ثلاث طابعات جاهزة:
        الكاشير            فاتورة العميل + درج النقدية
        كشري وطواجن        مطبخ الكشري والطواجن
        شاورما ومشويات     مطبخ الشاورما والمشويات
   • لكل واحدة: «تعديل» ← اختر طابعة ويندوز الخاصة بها
     ← علّم «الطابعة مفعّلة» ← حفظ ← «اختبار».

5) القائمة والأقسام
   • قائمة الطعام هي منيو أبو الدهب بأسعارها: 14 قسماً و92 صنفاً،
     وكل قسم مربوط بمطبخه (كشري وطواجن / شاورما ومشويات)،
     والمشروبات والحلويات على الكاشير فقط.
   • لكل قسم زر «✏️ تعديل» تختار منه الطابعة التي تخرج
     عليها تذكرة المطبخ لأصناف هذا القسم.

6) البيانات
   • كل بيانات المحل في مجلد  data  داخل مجلد البرنامج.
     لا تحذفه، وعند التحديث لا تكتب فوقه.
